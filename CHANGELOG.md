# Changelog

Public changelog for PDF Toolbox Online.

## V1 — Initial Public Tool Set

Current V1 includes tools for:

- Merging PDF files
- Splitting PDF files
- Compressing PDFs
- Signing PDFs
- Adding watermarks
- Rotating pages
- Deleting pages
- Reordering pages
- Extracting pages
- Protecting PDFs
- Unlocking PDFs
- Removing metadata
- Cropping PDFs
- Converting PDF, Word, JPG, PNG, and WebP files
- Compressing and resizing images
- Generating QR codes
- Converting webpages to PDF
