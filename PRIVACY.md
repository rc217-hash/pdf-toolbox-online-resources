# Privacy Notes

PDF Toolbox Online is designed for temporary browser-based file processing.

Website: https://pdftoolboxonline.com  
Privacy Policy: https://pdftoolboxonline.com/privacy

## File Handling

PDF Toolbox Online processes uploaded files temporarily so users can complete tasks such as merging, compressing, splitting, signing, watermarking, and converting documents.

Uploaded and processed files are automatically deleted after a limited retention period.

## No Account Required

Most tools are designed to work without requiring users to create an account.

## Sensitive Documents

Users should always review whether an online tool is appropriate for highly sensitive, regulated, or confidential documents.

For more details, see the official privacy page:

https://pdftoolboxonline.com/privacy
