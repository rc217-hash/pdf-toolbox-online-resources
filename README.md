# PDF Toolbox Online

PDF Toolbox Online is a browser-based PDF utility website for common document tasks such as merging, splitting, compressing, signing, watermarking, converting, organizing, and optimizing PDF files.

Website: https://pdftoolboxonline.com  
All Tools: https://pdftoolboxonline.com/tools

## Main Tools

- [Merge PDF](https://pdftoolboxonline.com/merge-pdf) — Combine multiple PDF files into one organized document.
- [Compress PDF](https://pdftoolboxonline.com/compress-pdf) — Reduce PDF file size for email, uploads, and storage.
- [Split PDF](https://pdftoolboxonline.com/split-pdf) — Extract pages or split large PDFs into smaller files.
- [Sign PDF](https://pdftoolboxonline.com/sign-pdf) — Draw or upload a visual signature and place it on a PDF.
- [Add Watermark](https://pdftoolboxonline.com/add-watermark) — Add custom text watermarks such as Confidential, Draft, or Final.

## Tool Categories

PDF Toolbox Online includes tools for:

- Organizing PDFs
- Compressing PDFs and images
- Signing and watermarking documents
- Converting PDF, Word, JPG, PNG, and WebP files
- Protecting, unlocking, and cleaning PDF metadata

See the full tool directory:  
https://pdftoolboxonline.com/tools
