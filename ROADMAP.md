# PDF Toolbox Online Roadmap

This roadmap outlines planned improvements and future tools for PDF Toolbox Online.

## Current V1 Focus

The current version focuses on fast, browser-based PDF utilities with simple upload, processing, and download workflows.

Main V1 tool categories:

- PDF organization
- PDF compression
- PDF signing
- PDF watermarking
- PDF conversion
- Image conversion
- Image compression
- Privacy and trust pages
- Tool tutorial videos

## Near-Term Development Priorities

The next planned tools are:

1. PowerPoint to PDF
2. Excel to PDF
3. PDF OCR
4. Redact PDF

## Future Tool Expansion

Future expansion may include:

- Edit PDF
- PDF Overlay
- Compare PDFs
- Create PDF
- Repair PDF
- Create PDF with a Camera
- PDF to PowerPoint
- PDF to Excel
- Add Page Numbers
- Extract Images from PDF
- PDF to PDF/A
- PDF/A to PDF
- Make PDF Searchable

## Future UX Improvements

Planned interface improvements include:

- Batch processing UI
- Before/after preview for image tools
- More document preview options
- More mobile-friendly workflows
- Improved tool result summaries

## Long-Term Goal

The long-term goal is to provide a broad, useful, privacy-conscious online PDF toolbox for everyday document tasks.
