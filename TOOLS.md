# PDF Toolbox Online Tool Directory

This page lists the public tools available on PDF Toolbox Online.

All tools are available at:  
https://pdftoolboxonline.com/tools

## Core PDF Tools

- [Merge PDF](https://pdftoolboxonline.com/merge-pdf)  
  Combine multiple PDF files into one document.

- [Split PDF](https://pdftoolboxonline.com/split-pdf)  
  Extract pages or split a large PDF into smaller files.

- [Compress PDF](https://pdftoolboxonline.com/compress-pdf)  
  Reduce PDF file size for email, web upload, or storage.

- [Rotate PDF](https://pdftoolboxonline.com/rotate-pdf)  
  Rotate all pages or selected pages in a PDF.

- [Delete Pages](https://pdftoolboxonline.com/delete-pages)  
  Remove unwanted pages from a PDF.

- [Reorder PDF Pages](https://pdftoolboxonline.com/reorder-pdf)  
  Rearrange page order in a PDF document.

- [Extract Pages](https://pdftoolboxonline.com/extract-pages)  
  Extract selected pages from a PDF.

- [Crop PDF](https://pdftoolboxonline.com/crop-pdf)  
  Crop PDF page margins and visible areas.

## Signing, Watermarking, and Security

- [Sign PDF](https://pdftoolboxonline.com/sign-pdf)  
  Add a visual electronic signature to a PDF.

- [Add Watermark](https://pdftoolboxonline.com/add-watermark)  
  Add custom text watermarks to PDF files.

- [Protect PDF](https://pdftoolboxonline.com/protect-pdf)  
  Add password protection to a PDF.

- [Unlock PDF](https://pdftoolboxonline.com/unlock-pdf)  
  Remove password protection when you know the current password.

- [Remove Metadata](https://pdftoolboxonline.com/remove-metadata)  
  Remove hidden PDF metadata before sharing.
